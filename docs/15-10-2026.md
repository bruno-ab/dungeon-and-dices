# 15-10-2026 — Mira overworld (Mana Seed)

## Padrão

- Overworld de NPCs com sheet fatiado segue o layout do Magus: `frames/{front,back,left,right}/00.png`…`04.png`.
- `SpriteCatalog.mira()` espelha `magus()` (idle_* + walk_* + alias `walk`).
- Composição Mana Seed: script `scripts/tools/build_mira_frames.py` (base + underwear + outfit + hair tingido).
- Walk do demo fica nas **linhas 4–7** do sheet 8×8 (64px); linhas 0–3 são poses.
- Placeholders procedurais antigos vão para `mira/_legacy/` (não referenciados).

## Escala na vila

Sprites Mana Seed (~32px úteis em célula 64) usam scale ~2.1; Magus (~150px) usa ~0.65 para altura visual parecida.
